# Privacy Policy for Smar

## 1. Data Collection
Our bot collects limited data to function correctly:
- **User IDs:** To save personal music playlists.
- **Server IDs:** To store server-specific settings (e.g., 24/7 mode, prefix).
- **Voice Channel IDs:** To manage music playback.

## 2. Data Usage
The data is used strictly for the functionality of the bot. We **do not** read or store your message content beyond command execution.

## 3. Data Storage
Data is stored securely in a local database. We **do not** share your data with any third parties.

## 4. User Rights
Users can request data deletion at any time by removing the bot from their server or contacting the developer.
